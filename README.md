# Índice Gen3 PT-BR — FireRed & LeafGreen (gen1recomp)

Índice de distribuição de mods em português para Pokémon FireRed e LeafGreen no **gen1recomp**.

## Usar no app

No gen1recomp: **Configurações → Mods → Índices → Adicionar**

```
LordSangreal/gen1recomp-indice-teste
```

O app busca `https://lordsangreal.github.io/gen1recomp-indice-teste/data/index.json`.

## Mods incluídos

- **Gen3 PT-BR FireRed - LeafGreen** (`firered-legenda-ptbr`)
  - Repositório: https://github.com/LordSangreal/gen3_frlg_pt-br_mod
  - Tradução para português do Brasil dos diálogos de Pokémon FireRed e LeafGreen.
