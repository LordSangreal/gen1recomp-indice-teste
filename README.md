# Índice Gen3 PT-BR — FireRed & LeafGreen (gen1recomp)

Índice exclusivo de distribuição de mods em português para **Gen 3** (Pokémon FireRed e LeafGreen) no **gen1recomp**.

## Usar no app

No gen1recomp: **Configurações → Mods → Índices → Adicionar**

```
LordSangreal/gen3-ptbr-firered-leafgreen-index
```

O app busca `https://lordsangreal.github.io/gen3-ptbr-firered-leafgreen-index/data/index.json`.

## Mods incluídos (Exclusivo Gen 3)

- **Gen3 PT-BR FireRed - LeafGreen** (`firered-legenda-ptbr`)
  - **Jogos compatíveis:** Pokémon FireRed e Pokémon LeafGreen (Gen 3)
  - **Repositório do mod:** https://github.com/LordSangreal/gen3_frlg_pt-br_mod
  - **Conteúdo:** Tradução para português do Brasil dos 6982 diálogos das ROMs.
